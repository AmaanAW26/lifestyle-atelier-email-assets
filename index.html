New Outlook and Outlook on the web

The current Outlook for Windows, and Outlook in a browser at outlook.com or office.com.

  1. Select the Settings gear at the top right.
  2. Choose Accounts, then Signatures.
  3. Select New signature and name it Lifestyle Atelier.
  4. Click inside the large editing box and paste (Ctrl + V on Windows, Cmd + V on Mac).
  5. Under Select default signatures, choose Lifestyle Atelier for new messages, and again for replies and forwards.
  6. Select Save.

Classic Outlook for Windows

The desktop app with File in the top menu.

  1. Go to File, then Options, then Mail.
  2. Select Signatures.
  3. On the E-mail Signature tab, select New and name it Lifestyle Atelier.
  4. Click inside the Edit signature box and paste with Ctrl + V.
  5. On the right, set New messages and Replies/forwards to Lifestyle Atelier.
  6. Select OK, then OK again.

If the key or icons do not appear after pasting in classic Outlook, place the cursor where the key should sit, select the picture icon in the signature editor, and insert the key image saved with the button below. Set its width to 40. Classic Outlook for Windows shows only the first frame of a moving image, so there the key appears still, facing forward, exactly as in the static version.

Outlook for Mac

  1. From the Outlook menu at the top of the screen, choose Settings (called Preferences on older versions).
  2. Select Signatures.
  3. Select the + button and name the new signature Lifestyle Atelier.
  4. Paste into the editing area with Cmd + V.
  5. Under Choose default signature, select Lifestyle Atelier for new messages and for replies and forwards.
  6. Close the window. The signature saves automatically.

Outlook on iPhone and Android

The mobile app keeps signatures simple, so it uses a text version.

  1. Copy the text below.
  2. In the Outlook app, open Settings from your profile picture, then Signature.
  3. Replace what is there with the copied text.
